# 订阅成本中枢二次 UX 修订

## Goal

将 `/subscriptions` 从初版成本洞察页修订为更紧凑、可信、可操作的订阅成本工作台。页面必须在桌面视口下清晰展示四个顶部指标和四个核心工作栏，并纠正预算语义：预算是全局月预算，不是单个 VPS 或订阅的属性。

## User Value

- 用户进入订阅页后能一屏判断本月成本来源、成本构成、年度成本与预算关系、近期续费压力。
- 用户可以直接从订阅名称打开编辑弹窗调整续费时间、备注、价格、标签等订阅事实，不需要单独订阅详情页。
- 用户设置不同基准货币时，页面成本列和图表文案都按实际基准货币展示，不写死 CNY。
- 年度趋势图同时展示月成本和月预算，超预算/低于预算区间清晰可辨，避免只展示单条成本曲线导致判断不足。

## Confirmed Facts

- 当前顶部四个指标在实际 v0.31.0 页面中仍分两行显示，需要通过实际浏览器截图验证，而不是只看 CSS。
- 当前 `subscription_budgets` 支持 `scope_type='vps'`，且 `SubscriptionRecord`/`CostRow` 暴露 `budget_status`，导致 UI 表达了 VPS 级预算概念。
- 当前后端已有真实的订阅支付方式字段 `subscriptions.payment_method`，可以作为成本构成维度。
- 当前 VPS 表已有 `vps_assets.country` / `region`，可以作为国家/地区成本构成维度。
- 当前统计 API 有 `cost_month_buckets`，但没有月预算历史序列，无法完成“月成本 vs 月预算”双曲线。
- 当前订阅页已有创建/编辑 Modal，可复用为订阅名称点击后的编辑入口。

## Requirements

- 顶部指标在桌面内容宽度足够时必须一行四列展示：月均成本、未来 30 天续费、预算风险、缺订阅资产。窄屏可降为两列或单列。
- 中部成本洞察改为桌面四栏：月成本、成本构成、年度趋势与风险、续费队列。较窄桌面降为两列，移动端单列。
- 月成本栏默认展示饼图，支持切换到 VPS 排行列表。VPS 排行按基准货币月成本从高到低排序，内容超高时在栏内滚动。
- 月成本饼图去掉右侧图例；鼠标 hover / 键盘 focus 显示 tooltip，包含 VPS 名称、原始付费价格、基准货币月成本、月付费占比。点击具体 VPS 仍应用 `vps_id` 筛选。
- 成本构成栏使用同一排行图，通过 segmented/tabs 切换服务商、分类、币种、支付方式、国家/地区五个维度。
- 年度趋势与风险图同时展示月成本和月预算两条线。成本高于预算的差值区域用超预算状态色填充，预算高于成本的差值区域用低于预算状态色填充，相等时不填充。
- 年度趋势图下方三个统计卡片移除，避免拥挤和重复表达。
- 预算模型在 UI 和新合同中收敛为全局月预算。用户可以按月调整预算；未调整的月份沿用上一个已配置月份的预算。
- 设置页订阅 tab 不再创建/编辑 VPS、服务商、标签、分类级预算；改为管理全局月预算时间线和基础订阅成本设置。
- 订阅明细表删除操作列；VPS/订阅名称列改为按钮/链接式单元格，点击打开订阅编辑弹窗。
- 订阅明细表删除预算/汇率列；分类、标签独立成列；基准货币成本列不得写死 CNY，列名使用动态基准货币或“基准货币成本”。
- 跳转 VPS 详情入口放入订阅编辑弹窗中，列表页不再单独展示“回到 VPS”。
- 保持 `/subscriptions?vps_id=<id>&create=1` 自动打开创建弹窗并预填 VPS；关闭时保留 `vps_id`、移除 `create=1`、清理草稿和错误。
- 图表失败不能让订阅明细不可用；核心列表和 overview 仍可独立加载。

## Acceptance Criteria

- [ ] 1440px 桌面视口下顶部四个指标在同一行；390px 无页面级横向溢出。
- [ ] 1440px 桌面视口下四个中部工作栏在同一行；1080px 可读且不挤压文字；390px 单列。
- [ ] 月成本栏支持饼图/排行切换；饼图无固定右侧图例；hover/focus tooltip 内容完整；点击 VPS 应用筛选。
- [ ] 成本构成支持服务商、分类、币种、支付方式、国家/地区五个真实维度。
- [ ] 年度趋势图展示月成本和有效月预算两条曲线，并填充成本高/预算高的差值区域。
- [ ] 后端统计 API 返回月预算 bucket，且预算沿用规则可测试。
- [ ] 订阅明细点击名称打开编辑弹窗；无操作列；无预算/汇率列；分类和标签独立列；成本列不写死 CNY。
- [ ] 设置页订阅 tab 可以管理全局月预算时间线，且不再暴露 VPS 级预算概念。
- [ ] 现有创建、编辑、深链创建、空态、错误态、筛选行为保留。
- [ ] 后端、前端、视觉脚本和构建验证通过；最终按 GitHub PR/CI/release/image 流程交付。

## Out Of Scope

- 不新增订阅详情页。
- 不做账单导入、成本预测、自动优化建议或报表导出。
- 不引入第三方图表库或状态管理库。
- 不改变 VPS 详情页和资产决策页的主业务结构。
