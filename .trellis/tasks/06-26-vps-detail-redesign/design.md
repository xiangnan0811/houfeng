# VPS 详情页重构设计

## 目标

把 `/vps/:vpsId` 默认视图重构为“综合基础信息面板 + 可选关注项”的资产工作台。页面必须让用户快速确认当前 VPS 基本情况，并在需要处理时知道下一步；在大多数稳定订阅期，页面应安静、紧凑、可扫描。更深层的成本、IP 质量、服务/域名、历史和基础资料通过明确入口进入弹窗或独立详情页。

## 设计原则

- 默认视图先服务一个常态问题：这台 VPS 当前情况如何？只有异常、临期、缺证据、取消/迁移流程时，才升权回答：现在应该怎么处理？
- VPS 基本情况必须默认可见，但只展示用户确认身份和状态所需的紧凑字段。
- 每个事实在默认视图中只承担一个角色：身份、状态、判断证据、主操作、详情入口或反馈。
- 正常事实降权，异常/阻塞事实升权。
- 下一步动作不是常驻大模块。稳定期只显示紧凑状态提示或不显示；异常期才展开为可操作提示。
- 下一步动作、证据摘要、状态提醒不能在默认页各自占一整横排；它们应合并到综合信息面板中的局部状态、关注项或行动槽。
- 文案必须短，避免解释性长段落；详细解释进入 tooltip、详情弹窗或操作确认。
- 基础信息排布必须使用能充分利用横向空间的 responsive grid，避免“某个字段右侧空着但放不下下一项”的死板列宽。
- 低频深度报告走“默认摘要 + 独立详情页”模式。
- 危险操作只在用户主动触发或当前状态必须处理时出现。
- 测试断言用户任务和能力保留，不锁死旧 section heading。

## 默认信息架构

### 1. 综合基础信息面板

职责：

- 确认当前页面是哪台 VPS。
- 展示当前 VPS 的最小必要基础情况。
- 承载全局更多菜单。
- 内嵌低权重状态/关注项，不再额外铺整行证据和提醒。

默认字段：

- VPS 名称。
- Provider。
- 地区 / 数据中心。
- 产品规格。
- IPv4 或 SSH Host。
- SSH 端口。
- 操作系统。
- 生命周期。
- 使用状态。
- 续费决策。
- 监控实例数。
- IP 质量一句话摘要。

不默认展示，进入“基础资料”弹窗：

- VPS ID。
- Provider ID。
- 订单号。
- IPv6。
- SSH 用户。
- 虚拟化。
- 标签。
- 备注。
- 归档时间。

操作：

- 默认区最多一个主 CTA；其余进入更多菜单。
- 更多菜单保留：编辑基础信息、记录经验、创建/更新订阅、延长有效期、接入/升级 agent、关联已有监控实例、新增服务、新增域名、归档/恢复、返回 VPS 列表。
- `取消/退役` 不作为更多菜单常驻项；它只在顶部 `当前判断` 判定当前 VPS 处于取消、迁移、已取消自动续费且需要处理、或预览存在 warning/blocker 时显示。

布局建议：

- 面板顶部：VPS 名称 + 少量状态 badges + 主/次操作槽。
- 面板主体：字段密度较高的事实 grid。
- 面板右侧或底部：关注项 chips / 小行，不使用独立大 section。
- 字段宽度按内容类型分配：短状态字段可更窄，访问地址/IP 可更宽，避免固定 6 等分导致空白浪费。
- 续费状态不单独占框体；作为右侧“观测状态/观测证据”中的紧凑事实行展示。

### 2. 状态感知关注项

职责：

- 在稳定期保持低干扰：并入综合基础信息面板的状态 chip 或不显示。
- 在异常、临期、缺证据、取消/迁移流程时，用 `buildVPSDecisionModel` 选出单一下一步动作。
- 异常期只展示短标题、短原因和一个主 CTA，但仍尽量放在综合面板的关注项区域，而不是独立占整行。

显示规则：

- `normal`：不使用独立提示条；显示低权重 chip 或完全不显示。
- `notice`：使用综合面板内的关注项行/卡，不独占页面横排。
- `alert` / `critical`：可展开为小型行动块，但不能占据半个首屏，也不应与证据摘要分裂成多个横排。
- 主文案控制在 1 行标题 + 1 行短原因，避免段落解释。

保留现有模型输入：

- `detail`。
- `timeline`。
- `primarySubscription`。
- `subscriptionLoadFailed` / `subscriptionError`。
- services/domains count。
- monitoring instance summary。

需要调整：

- 当前 `VPSDecisionBoard` 内部过多层级应拆分或重排。
- `调整决策` 和 `组合决策` 不再在 Hero 和 DecisionBoard 双重出现。
- 主 CTA 由 next action 决定，但只有非稳定态才升为明显按钮；组合决策降为次级入口。

### 3. 证据摘要入口

职责：

- 在综合面板中用短行/chip 展示影响判断的证据。
- 不按领域平均分配卡片。
- 不展示完整矩阵、表格或全量历史。
- 不作为独立大 section 常驻；除非页面处于异常/临期状态，需要临时升权。

证据分组建议：

- 阻塞 / 需要立即处理。
- 风险 / 需要核对。
- 已具备证据。
- 低权重上下文。

证据来源：

- 订阅/成本：月成本、续费日、续费方式、是否已取消自动续费。
- 监控实例：健康状态、活跃异常数、最近心跳。
- IP 质量：评分或结论、最高风险、解锁概览、完整报告入口。
- 服务/域名：数量和是否缺上下文。
- 历史：最近判断记录和经验摘要。
- 资料质量：只在缺关键字段时显著显示；资料正常时放低权重。

续费/到期文案规则：

- 正常续费：`X 天后续费`。
- 超过 30 天：`X 个月后续费`。
- 超过一年：仍显示月数，例如 `14 个月后续费`。
- 已取消自动续费：`已取消自动续费 · X 天后到期` 或 `已取消自动续费 · X 个月后到期`。
- 不使用独立“续费提醒”框；该信息归入观测/状态摘要。

### 4. 默认页下半部分

默认页不再继续堆“成本卡片 / IP 质量 / 证据摘要 / 状态提醒”这类横向 section。首个综合面板之后，只保留低密度的页面级区域：

#### 4.1 关联概览

目的：

- 告诉用户这台 VPS 关联了哪些对象。
- 提供进入详情的入口。
- 不展示全量表格。

内容：

- 订阅：当前 active 订阅、到期/续费状态、入口。
- 监控实例：数量、健康/心跳摘要、入口。
- 服务/域名：数量、入口。
- 历史：记录数、最近一条摘要、入口。

表现：

- 紧凑横向 list 或 2x2 小行。
- 每项 1 行标题 + 1 行事实 + 1 个详情入口。
- 正常态不使用强色块；有缺口/异常时对应项升权。

#### 4.2 情境工作区

默认隐藏或轻量显示，只有状态需要时出现：

- 取消/迁移/已取消自动续费且需要处理：不在中部情境工作区展示；由顶部 `当前判断` 显示 `处理取消/退役`，点击后打开影响范围 modal。
- 订阅缺失：显示创建/更新订阅入口。
- 未关联监控实例：显示创建/关联监控实例入口。
- IP 质量失败/高风险：显示报告入口和风险摘要。

这些工作区不能多个同权展开；如果多个问题并存，按优先级只升权最重要的一个，其余进入关注项列表。

#### 4.3 操作反馈

操作成功/失败提示不再插入成大区块：

- 成功反馈靠近综合面板顶部或相关入口。
- 错误反馈使用 alert，但不长期占据页面结构。
- 弹窗内操作错误优先留在弹窗内。

### 5. 次级详情入口

保留现有 Modal / route 能力：

- 基础资料详情 / 编辑基础信息。
- 订阅详情 / 创建/更新订阅。
- 监控观测 / 接入/升级 agent / 关联已有监控实例。
- IP 质量完整报告 `/vps/:vpsId/ip-quality`。
- 服务资产详情 / 新增服务。
- 域名资产详情 / 新增域名。
- 资产历史详情 / 记录经验。
- 取消/退役。
- 归档/恢复确认。

## 完整默认页布局草案

顺序：

1. 综合基础信息面板。
2. 可选的最高优先级情境工作区。正常态不显示。
3. 关联概览。
4. 轻量操作反馈区域。无反馈时不占位。

不默认渲染：

- 独立 `VPSDecisionBoard` 大面板。
- 独立 `VPSIPQualitySection` 大面板。
- 独立 `成本卡片`。
- 全量服务/域名表。
- 全量资产历史。
- 全量基础资料 grid。
- 常驻危险区。

## V5 完整默认页方案

V5 将默认页定义为一个完整但克制的资产概览，而不是继续围绕单个卡片反复调整。页面默认状态以“稳定订阅期”为基准：用户进入后先确认身份、访问方式、续费/观测证据和关联对象是否正常；只有最高优先级问题需要处理时，页面才在综合面板下方插入情境工作区。

### 页面顺序

1. 顶部综合基础信息面板。
2. 情境工作区插槽。稳定期为空，不显示标题、不占位。
3. 关联概览。
4. 单台 VPS 详情工作区。
5. 操作反馈。仅在刚完成操作或读取失败时出现，且靠近相关区域。

这四层之外不再追加默认 section。IP 质量、订阅成本、服务/域名、历史和基础资料都只能通过综合基础信息、关联概览、单机台账中的摘要或入口出现。

Mockup 中用于解释异常态、操作反馈、移动端折叠或菜单分组的“状态变体示意”不属于最终页面默认内容；它们只能作为设计评审辅助。最终实现中，稳定期页面主体渲染综合基础信息面板、关联概览和单机台账，不渲染额外说明区。

### 顶部综合基础信息面板

桌面布局：

- 面板左侧为身份与事实区，右侧为判断摘要区。
- 身份行显示：VPS 名称、生命周期、使用状态、续费决策、监控实例数量。
- 不在标题下方重复展示 provider、地区、IP 这类已在事实 grid 中出现的 pills。
- 右上操作区最多显示一个被升权的主 CTA；稳定期没有显著主 CTA。稳定期可保留 `调整决策`、`基础资料` 和 `更多`，其中 `组合决策` 进入 `更多` 菜单。
- 事实区使用内容感知 grid，不固定平均列：
  - 短字段窄列：Provider、系统、生命周期、使用状态、续费决策。
  - 中字段中列：地区 / 数据中心、规格、监控实例数。
      - 长字段宽列：IPv4 / SSH Host + 端口、IP 质量一句话摘要、订阅摘要。
- `IPv4 或 SSH Host` 与 `SSH 端口` 在默认页合并为一项“访问”，避免端口单独占一个低信息密度卡片。
- `地区 / 数据中心` 在有数据中心时显示 `国家 / 地区 · 数据中心`；没有数据中心时只显示位置，不补内部占位。
- `IP 质量` 显示一句判断摘要，例如 `80 · 2 风险 · 3 可用`；完整矩阵只通过报告入口进入。
- 订阅成本不独立成卡；事实区可展示月成本，续费时间和自动续费状态归入右侧判断摘要。

判断摘要区：

- 标题可以使用 `判断摘要` 或 `观测状态`，但职责不是列来源事实，而是给出跨域归纳。
- 稳定期第一行显示短结论，例如 `证据可读 · 暂无必须处理动作`。
- 续费/到期显示在判断摘要内部，不独占框体：
  - 正常续费：`X 天后续费`。
  - 超过 30 天：`X 个月后续费`。
  - 超过一年：仍显示月数。
  - 已取消自动续费：`已取消自动续费 · X 天后到期` 或 `已取消自动续费 · X 个月后到期`。
- 继续显示最多 2 条跨域判断，例如 `运行与订阅证据一致`、`IP 风险未改变续费判断`、`无需补证据`。
- 不显示心跳、服务/域名数量、最近历史、IP 报告更新时间等来源事实；这些内容归入下方关联概览或对应详情入口。
- 稳定期不在判断摘要区放 `调整决策`、`组合决策`。`调整决策` 如需常驻，放到顶部操作区；`组合决策` 进入 `更多` 菜单。
- 判断摘要必须短字段化，不写解释句或主观判断段落。推荐只保留 3 行以内：`决策`、`续费`、`动作`；每行是短值，例如 `观察`、`2 个月后`、`无`。
- 当 `动作` 为 `取消/退役` 时，判断摘要底部显示一个小型处理按钮 `处理取消/退役`，打开 `cancellation` modal；这不是直接执行取消。正常状态下 `动作` 显示 `无`，不显示按钮。
- 综合基础信息面板不再渲染单独的“详情入口”chip 行；这些入口由下方关联概览承担，避免顶部和下方重复。

### 情境工作区

情境工作区只在最高优先级状态需要处理时出现，稳定期完全不渲染。它不是新的常驻 “下一步动作” section，而是一个临时插入的窄工作块。

显示规则：

- 只展示一个最高优先级问题。
- 文案限制为一行标题、一行短原因、一个主 CTA、最多两个次级入口。
- 其他问题降为综合面板内关注项或关联概览对应项的状态。
- 如果只是普通观察、证据可读、续费未临近，则不显示。

例子：

- 续费 7 天内且已取消自动续费：标题 `续费临近，自动续费已取消`，主 CTA `处理续费决策`。
- 缺 active 订阅：标题 `缺少当前订阅证据`，主 CTA `创建/更新订阅`。
- 未关联监控实例：标题 `缺少运行观测`，主 CTA `创建监控实例`。
- IP 质量高风险或报告失败：标题 `IP 质量需要核对`，主 CTA `查看 IP 质量报告`。
- 取消/退役相关状态不进入中部情境工作区；它固定由顶部 `当前判断` 的状态动作承载，避免与判断摘要重复。

### 关联概览

关联概览是默认页下半部分的常驻导航性内容。它的职责是告诉用户这台 VPS 连接了哪些对象，并给出入口，不承担全量展示；单机台账负责展示这台 VPS 本身的近期记录和承载事实。

默认项：

- 订阅：当前 active 订阅、续费/到期状态、月成本或计费周期、入口。
- 监控实例：实例数量、健康/心跳摘要、入口。
- IP 质量：评分或结论、最高风险或可用概况、完整报告入口。
- 服务与域名：服务数量、域名数量、入口和新增入口。
- 资产历史：历史数量、最近一条判断/经验摘要、入口和记录经验入口。

表现规则：

- 不使用固定 2x2。关联概览使用自适应横向/多列布局，按可用宽度自然排布 5、7、8 个块。
- 每项只允许：可点击标题、状态 badge、1 行主事实、1 行补充事实、少量独有临时动作。
- 正常项不使用强色块；异常项才在左边或状态 badge 中显示 tone。
- 不显示完整服务表、域名表、订阅成本明细、历史时间线。
- 与顶部判断摘要分工：关联概览承载来源事实和入口；顶部判断摘要只承载这些来源事实合成后的结论，二者不能重复列同一事实。
- `查看`、`管理` 这类通用入口按钮不显示；点击每项标题进入对应详情或打开对应详情弹窗。
- `延长`、`接入`、`新增`、`记录` 等每项独有的临时管理动作可以保留为低权重按钮，并优先打开弹窗/现有 modal，不把用户带离默认页。
- 关联概览标题区不显示使用说明文案，例如“标题进入详情”“只保留独有临时动作”。可交互性由标题 link 样式和 hover/focus 表达。

### 单台 VPS 详情工作区

综合基础信息和关联概览不能把页面变成纯中转页。默认页下方需要提供一块直接服务“管理、查看、记录单台 VPS”的内容展示，但仍不能回到全量表格堆叠。

职责：

- 展示这台 VPS 的近期记录、维护备注、承载说明和关键变化。
- 让用户不用进入多个详情页，也能快速回忆“这台机器为什么这样处理、最近发生过什么、现在承载什么”。
- 提供记录和维护入口，但不抢顶部判断主线。

建议内容：

- `运维台账`：用途、标签、维护窗口、备注状态等结构化字段。
- `近期记录`：最近 3 条经验/资产历史，每条控制为日期 + 类型 + 极短摘要。
- `承载清单`：当前主要服务/域名，最多 3 条，使用表格/列表字段而非散文描述。
- `关键变化`：续费决策、IP 质量、监控状态、订阅状态的最近变化摘要；没有变化时隐藏。

表现：

- 使用结构化台账样式，优先短字段、短行、列表；避免散文式说明和解释段落。
- 可以是双栏或三栏的低密度详情区，而不是入口卡片。
- 内容必须是这台 VPS 本身的可读事实或记录，不是“去哪里查看”的导航说明。
- 各小块可为空态隐藏；没有内容时不要用大面积空态。
- 这一区域不设计后续独立详情页，只使用已有数据和已有 modal/route 入口。

### 操作入口分级

页面操作按用户优先级分四层：

1. 升权主 CTA：只来自当前最高优先级情境，稳定期没有显著主 CTA。
2. 顶部状态动作：`处理取消/退役` 只在顶部 `当前判断` 中按状态出现，打开影响范围 modal，不直接执行。
3. 常用维护入口：`调整决策`、`基础资料`，作为顶部按钮出现；`记录经验` 可放在详情工作区或更多菜单。
4. 关联对象入口：订阅详情、监控观测、IP 质量报告、服务/域名、资产历史，在关联概览标题中出现，不在综合面板底部重复。
5. 危险/低频操作：归档、恢复、解除关联等仍走更多菜单或对应 modal，必须保留确认流程。

`更多` 菜单建议分组但不引入复杂导航：

- 维护：编辑基础资料、记录经验、组合决策。
- 订阅：创建/更新订阅、延长有效期。
- 监控：接入/升级 agent、关联已有监控实例。
- 承载：新增服务、新增域名。
- 生命周期：归档/恢复。

`取消/退役` 从更多菜单移出，避免正常状态下展示危险入口；它只有在 `当前判断` 判定需要处理时出现。

### 状态语义

默认页只使用四档 tone：

- `normal`：事实正常、可观察，不升权。
- `notice`：需要核对但不阻塞，显示轻量关注项。
- `alert`：影响续费/运行判断，出现情境工作区。
- `critical`：已过期、严重监控异常、取消/退役 blockers 或危险状态；取消/退役用顶部 `当前判断` 的状态动作表达，其它最高优先级问题才进入情境工作区。

状态颜色不能按子域各自发挥。订阅、监控、IP 质量、生命周期都必须映射到这四档，再由页面统一决定展示强度。

### 响应式行为

- 1280px 以上：综合面板左右两栏，左侧事实 grid + 右侧观测状态。
- 960px 到 1279px：综合面板上下排列；事实 grid 保持 2 到 3 列，观测状态变为横向短行。
- 720px 以下：VPS 名称、状态 badges、操作区、事实项、观测状态、关联概览全部纵向排列；默认显示项不增加，只改变排列。
- 移动端不显示单独大块“下一步动作”；异常时情境工作区仍限制为短块。
- 所有按钮和 badge 必须允许中文换行或收缩，不能挤出容器。

### 空态与失败

- 订阅读取失败显示 `订阅证据暂不可用`，不能误判为缺 active 订阅。
- IP 质量读取失败显示 `报告暂不可用`，保留详情入口或重试入口，不伪造分数。
- 没有监控实例显示为证据缺口；如果当前状态不依赖监控，它只是 notice，不默认占大块。
- 服务/域名为 0 是普通上下文，不默认当成风险。
- 基础字段缺失只影响对应事实项；除非缺少访问地址、Provider 等关键事实，否则不升权为页面级问题。

### 文案边界

- 默认页不出现 `CRUD`、`Target`、`联动`、`证据覆盖`、`低频采集` 这类内部实现词。
- 短句优先，避免解释性段落。
- 操作按钮用动词开头，例如 `创建/更新订阅`、`查看监控`、`记录经验`。
- 入口命名稳定：`基础资料`、`订阅详情`、`监控观测`、`IP 质量报告`、`服务/域名`、`资产历史`。

## 状态优先级

从高到低：

3. 续费 7 天内或已过期。

## 跨页面关联与操作设计

VPS 详情页大体框架继续采用 V15 已确认的三层结构：综合基础信息、关联概览、单机台账。新增设计重点不是推翻主体结构或再增加导航层，而是补足默认页下方的 IP 质量概况，并给所有入口建立统一的弹窗操作语法，让用户在当前 VPS 上完成单台管理，也能一跳进入深度页面。

### 入口语法

页面上只保留四类入口：

1. 顶部常用维护：`调整决策`、`基础资料`、`更多`、`返回列表`。
2. 关联概览标题：进入该关联对象的详情或完整页面。
3. 关联概览快捷动作：只放该关联对象独有的临时管理动作，例如 `延长`、`接入`、`新增`、`记录`。
4. 更多菜单：低频、组合、生命周期和跨域动作。

设计规则：

- 标题点击永远表示“看详情/进入深度上下文”，不表示新建或修改。
- 快捷动作永远表示“在当前 VPS 上快速处理”，只打开本页 modal。
- `查看`、`管理` 这类通用按钮不出现。
- 不在 UI 中显示“标题可点击”“只保留快捷动作”等说明文字；可交互性由链接样式、hover/focus 和可访问名称表达。
- 弹窗用于单台 VPS 的短流程；跳页用于信息量大、需要比较或已有完整页面的流程。
- 跳页必须尽量携带当前 VPS 上下文，避免用户到新页面后重新查找。

### V17 固定补充

V17 不再沿用 V16 的“内部子详情/抽屉示意”方向。V17 的基准是：V15 主体结构固定，默认页继续展示当前 VPS 的基本情况、关联概览和单机台账；本轮只补充两个硬规则。

1. 默认页下方必须展示 `IP 质量概况`。它不是完整报告，也不是替代 `/vps/:vpsId/ip-quality` 的详情页，而是让用户在 VPS 详情页不用跳转也能知道当前 IP 是否值得关注。
2. VPS 详情页内所有快速管理与局部详情统一使用居中弹窗/modal。禁止抽屉；禁止点击后在页面中插入新的工作区、折叠面板或详情段落。

`IP 质量概况` 建议放在 `单机台账` 下方，作为默认页最后一个直接可读的概况区。它要比关联概览中的 IP 质量卡更具体，但比完整报告更克制：

- 左侧显示当前结论：分数、风险等级、报告时间、是否过期。
- 中部显示 3 到 5 个核心信号：归属/ASN、机房识别、代理/VPN、滥用/黑名单、地区一致性。
- 右侧显示服务解锁概览：可用、受限、未知数量；只列代表性服务，不展开完整矩阵。
- 标题 `IP 质量概况` 可点击进入 `/vps/:vpsId/ip-quality`；区内只保留 `打开完整报告` 这类必要入口，不放创建、编辑、刷新等管理动作。
- 无报告、失败或过期时必须诚实显示 `无报告`、`报告暂不可用`、`已过期`，不能伪造评分。

弹窗规则：

- `基础资料`、`调整决策`、`创建/更新订阅`、`延长有效期`、`监控观测`、`接入/升级 agent`、`关联已有监控实例`、`服务详情`、`域名详情`、`资产历史`、`记录经验`、`取消/退役`、`新增服务`、`新增域名` 都必须打开本页 modal。
- modal 采用居中覆盖层，宽度按任务分级：资料/表格类使用宽弹窗，短表单使用中弹窗，危险确认使用窄弹窗。
- modal 内显示当前 VPS 识别条和当前任务所需的 3 到 5 个关键摘要，不重复整页基础资料。
- modal 内的保存、重试、危险确认、错误提示都留在弹窗内部，不在默认页新增区域。
- 关闭 modal 后，默认页仍回到 V15 主体结构；操作结果只更新相关摘要或显示短 toast/alert，不生成新的常驻模块。

生产视觉约束：

- V17 mockup 只确认信息架构、模块顺序、字段密度、弹窗交互和 IP 质量概况内容范围。
- 正式实现必须使用项目现有视觉体系：`web/src/styles/tokens.css` / `atoms.css` / `pages.css` 中的 tokens、`.btn`、`.badge`、`.page-panel`、`.section-heading`、`.modal-content`、`.data-table`、tone classes 和现有 BEM 风格。
- 不复制 mockup 的浅色卡片配色、阴影、圆角、按钮样式或 `.v17-*` 类名；不新增 page-local CSS 文件。
- 新增样式落在现有全局样式体系中，颜色/间距/字号/圆角/阴影全部走 `var(--...)`，状态色走 `--color-state-*` 和 `color-mix(...)`。
- 页面必须在 houfeng dark、houfeng light、classic dark 三种主题下可读；V17 的白底预览不能成为 dark-first 主题的例外。

### 顶部操作

`调整决策`

- 位置：综合基础信息标题区右侧，放在 `基础资料` 左侧。
- 行为：打开现有 `decision` modal。
- 目的：单台 VPS 的续费/保留/取消/迁移判断，属于常用维护，不进入关联概览。

`基础资料`

- 位置：综合基础信息标题区右侧。
- 行为：打开 `facts-detail` modal；modal 内提供编辑入口，再进入 `facts` 编辑 modal。
- 目的：默认页不展示全量字段，但用户能快速核对完整资料。

`更多`

- 位置：顶部右侧。
- 分组：
  - 维护：`记录经验`、`组合决策`。
  - 订阅：`创建/更新订阅`、`延长有效期`。
  - 监控：`接入/升级 agent`、`关联已有监控实例`。
  - 承载：`新增服务`、`新增域名`。
  - 生命周期：`归档`、`恢复`。
- `组合决策` 行为：跳转 `/asset-decisions?view=needs_decision&renew_within_days=30&vps_id=<id>`。它是跨 VPS/组合视角，不放在当前判断区域。
- `取消/退役` 不放在更多菜单；它只作为 `当前判断` 内的状态动作出现。
- 危险操作必须继续走现有确认或影响范围弹窗，不从关联卡片直接执行。

`当前判断` 状态动作

- 位置：综合基础信息右侧 `当前判断` 内，紧跟 `决策 / 续费 / 动作` 三行。
- 显示条件：`renewal_decision in migrate|cancel|auto_renew_cancelled`，或 `lifecycle_status in to_migrate|to_cancel|cancelled`，或已加载的 cancellation preview 存在 warnings/blockers。
- 不显示条件：稳定 active/keep/auto_renew、普通观察、未加载 preview 且没有取消/迁移/已取消自动续费信号。
- 文案：`动作` 行值为 `取消/退役` 时显示按钮 `处理取消/退役`；否则 `动作` 行为 `无`，不渲染按钮。
- 行为：打开 `cancellation` modal，modal 内加载/刷新取消影响预览；点击按钮不直接提交任何生命周期变更。

### 关联概览入口矩阵

#### 订阅

默认事实：

- active 订阅、金额/周期、续费或到期时间、自动续费状态。
- 订阅读取失败显示 `订阅证据暂不可用`，不等同于缺订阅。
- 成功加载且无 active 订阅才显示 `未记录当前订阅`。

标题行为：

- 有订阅或需要跨订阅比较：跳转 `/subscriptions?vps_id=<id>`。
- 如果页面需要提供“快速编辑当前订阅”，后续可扩展为标题打开订阅明细 modal，但当前范围优先复用订阅中枢。

快捷动作：

- `延长`：打开 `validity-extension` modal。
- 有 active 订阅时显示 `更新`：打开 `subscription` modal，表单应以后续实现中的订阅维护语义呈现，不暗示重复新建。
- 无 active 订阅时显示 `创建`：打开 `subscription` modal。

深链/跨页规则：

- 从外部需要创建/更新订阅时可使用 `/subscriptions?vps_id=<id>&create=1`。
- 从资产决策页进入单台处理继续使用 `/vps/<id>?workbench=subscription`。
- VPS 详情页内创建/更新优先本页 `subscription` modal，避免离开当前上下文。

#### 监控实例

默认事实：

- 监控实例数量、健康摘要、最近心跳、告警/异常计数。
- 无实例是观测缺口，但只有当前状态依赖运行证据时才升权为情境工作区。

标题行为：

- 0 个实例：打开 `monitoring-instance-evidence` modal，展示空态和接入/关联入口。
- 1 个实例：跳转 `/monitoring/<monitoring_instance_id>`，进入完整运行观测。
- 多个实例：打开 `monitoring-instance-evidence` modal，列出实例并提供逐个进入监控详情的入口。

快捷动作：

- `接入/升级`：调用现有 `openMonitoringAgentWorkbench`。
  - 0 个实例：打开 `monitoring-instance-create` modal。
  - 1 个实例：跳转 `/monitoring/<id>?onboarding=1&return_vps=<vpsId>`。
  - 多个实例：打开 `monitoring-instance-evidence` modal。
- `关联`：打开 `monitoring-instance-link` modal，可放在卡片二级动作或更多菜单。

返回规则：

- 从 VPS 创建或升级 agent 后进入监控详情时必须保留 `return_vps=<id>`；监控接入弹窗完成按钮显示 `完成并返回 VPS`。
- 纯查看监控详情不强制带 `return_vps`，但监控页 header 已有 VPS 关联链接，可返回对应 VPS。

#### IP 质量

默认事实：

- 一句话摘要：评分/风险/可用概况，例如 `80 · 2 风险 · 3 可用`。
- 无报告、失败、过期要诚实展示，不伪造分数。

标题行为：

- 跳转 `/vps/<id>/ip-quality`。
- 如摘要绑定特定报告，可跳转 `/vps/<id>/ip-quality?report_id=<reportId>`。

快捷动作：

- 默认不放快捷动作。IP 质量是低频深度报告，不在 VPS 详情页内做二级操作。
- 报告失败时可在异常状态中提供 `查看报告` 或 `重试/等待采集`，但不常驻。

返回规则：

- IP 质量页保留 `返回 VPS 详情`。

#### 服务与域名

默认事实：

- 服务数、域名数、最多 1 个代表性承载项、探测关联数量。
- 0 服务/0 域名是承载信息缺口，不默认作为风险。

标题行为：

- 如果服务和域名仍合并为一张关联卡：点击标题打开轻量 `services-detail`/`domains-detail` 组合 modal 或默认打开服务/域名详情 modal 中的合并视图。
- 如果后续拆为两张卡：`服务` 打开 `services-detail` modal，`域名` 打开 `domains-detail` modal。
- modal 内的探测对象 ID 继续跳转 `/targets/<targetId>`。

快捷动作：

- `新增`：打开一个小菜单，包含 `新增服务`、`新增域名`。
- `新增服务` 打开 `service` modal。
- `新增域名` 打开 `domain` modal。

跳页规则：

- Target 属于运行探测深度上下文，最终 UI 可显示为“探测对象”；只有用户点具体 Target 链接时跳转，不在卡片标题直接跳 Target。

#### 资产历史

默认事实：

- 最近 1 条判断/经验摘要、历史数量、最近记录时间。
- 不显示全量时间线。

标题行为：

- 打开 `timeline-detail` modal。

快捷动作：

- `记录`：打开 `experience` modal。

规则：

- 单机台账中的近期变更行也可打开 `timeline-detail`，但不重复放多个“查看历史”按钮。

#### 基础资料

基础资料不再作为关联概览卡片重复出现。

- 顶部 `基础资料` 打开 `facts-detail`。
- 资料缺关键字段时，对应事实项显示缺失状态；只有缺 Provider、访问地址等关键事实时进入情境工作区。

### 情境工作区与关联入口的关系

情境工作区不是新的入口集合，只是把最高优先级问题临时升权。它必须复用同一套动作：

- 缺订阅：主 CTA `创建/更新订阅` -> `subscription` modal；次入口 `订阅中枢` -> `/subscriptions?vps_id=<id>`。
- 续费临近/已取消自动续费：主 CTA `调整决策` 或 `延长有效期`，依据 decision model；次入口可到订阅中枢。
- 未接入监控：主 CTA `接入/升级 agent` -> `monitoring-instance-create` modal；次入口 `关联已有` -> `monitoring-instance-link` modal。
- 监控严重异常：主 CTA `查看监控实例` -> `/monitoring/<id>` 或实例证据 modal。
- IP 质量高风险/失败：主 CTA `查看 IP 质量` -> `/vps/<id>/ip-quality`。
- 取消/退役相关状态不使用情境工作区；顶部 `当前判断` 中显示 `处理取消/退役` -> `cancellation` modal。

稳定期不显示情境工作区；关联概览和单机台账已经足够。

### 单机台账中的操作边界

单机台账不是第二个导航区。它只展示这台 VPS 的可读事实和近期记录：

- `运维字段`：用途、标签、维护窗、备注状态。编辑入口只放一个低权重 `编辑资料` 或复用顶部基础资料。
- `近期变更`：最近 3 条，点击行打开 `timeline-detail`。
- `承载清单`：最多 3 条服务/域名；具体服务/域名详情仍进对应 modal，探测对象链接在 modal 内出现。
- 如果某块无内容，隐藏或显示极短空态，不用大段提示。

### URL 与 deep-link 策略

现有可复用参数：

- `/vps/<id>?workbench=subscription`：打开创建/更新订阅。
- `/vps/<id>?workbench=monitoring` 或 `monitoring-instance-create`：打开监控接入流程。
- `/vps/<id>?workbench=cancellation`：处理取消/退役。
- `/subscriptions?vps_id=<id>`：订阅页过滤当前 VPS。
- `/subscriptions?vps_id=<id>&create=1`：订阅页打开创建面板并预填 VPS。
- `/monitoring/<id>?onboarding=1&return_vps=<vpsId>`：监控详情打开接入弹窗并允许完成后返回 VPS。
- `/vps/<id>/ip-quality` 和可选 `?report_id=<reportId>`：IP 质量报告。
- `/targets/<targetId>`：Target 详情。

建议补充但不作为首轮硬依赖：

- 扩展 VPS `workbench` 查询值到 `facts`、`decision`、`experience`、`service`、`domain`、`timeline`、`services`、`domains`，便于外部页面直接回到当前 VPS 的具体弹窗。
- 如实现扩展，打开后继续消费并清理 `workbench` 参数，保持现有深链行为一致。

### 用户流程覆盖

稳定巡检：

1. 打开 VPS 详情。
2. 首屏确认身份、访问、订阅、监控、IP 质量和当前判断。
3. 在关联概览点标题进入需要核对的深度页；无动作时不被大块 CTA 干扰。

订阅处理：

1. 无订阅或临近续费时，情境工作区升权。
2. 创建/更新订阅、延长有效期在本页 modal 完成。
3. 需要看历史账单或比较成本时，从订阅卡标题进入 `/subscriptions?vps_id=<id>`。

监控接入/升级：

1. 点击监控卡 `接入/升级`。
2. 没有关联则创建监控实例；创建成功后进入监控详情接入弹窗。
3. 已有关联则直接进入监控详情接入/升级，并带 `return_vps`。
4. 多实例先在证据 modal 中选实例。

IP 风险核对：

1. VPS 默认页只看一句话质量摘要。
2. 点击 IP 质量标题进入报告页。
3. 报告页查看 provider/service/历史后返回 VPS。

服务/域名补录：

1. 在服务/域名卡点 `新增`，选择服务或域名。
2. 在本页 modal 中完成记录；需要探测对象详情时从详情 modal 中点具体 Target。

记录经验：

1. 在资产历史卡点 `记录` 或更多菜单点 `记录经验`。
2. 保存后单机台账近期变更刷新。
3. 点击历史标题查看完整 timeline modal。

取消/退役：

1. 只有取消、迁移、已取消自动续费需要处理、或预览存在 warnings/blockers 时，顶部 `当前判断` 显示 `处理取消/退役`。
2. 点击后进入 `cancellation` modal 查看订阅、监控实例、探测对象影响范围。
3. 归档/恢复继续使用独立确认，不从卡片直接执行。

## VPS 内部子详情设计

本节只设计 VPS 详情体系内部的子详情页面/弹窗。外部订阅中枢、监控详情、Target 详情、组合决策页只作为跳转目标，不在本任务内重构。

### 子详情类型

VPS 详情体系内有两类子详情：

1. **本页弹窗 / modal**：基础资料、创建/更新订阅、延长有效期、监控观测、接入/升级 agent、关联已有监控实例、服务详情、域名详情、资产历史、记录经验、取消/退役、新增服务、新增域名。
2. **VPS 子路由**：`/vps/:vpsId/ip-quality`，用于 IP 质量完整报告。

本页弹窗服务“快速管理与局部核对”，不能做成全局工作台。VPS 子路由服务“低频深度分析”，可以承载更长内容，但必须保留清晰返回当前 VPS 的路径。

### 统一结构

每个子详情打开后都按同一结构组织：

1. 子详情标题：用户任务名，不使用内部实现词。
2. 当前 VPS 识别条：VPS 名称、Provider/地区、生命周期或关键状态。不要重复一整套基础事实。
3. 关键摘要：最多 3 到 5 个短字段，先回答当前子详情的核心状态。
4. 主内容：表格、列表、表单或报告矩阵。
5. 局部动作：只放与当前子详情直接相关的动作。
6. 反馈与确认：错误、成功、危险确认留在当前子详情内。

禁止：

- 在子详情标题或说明中出现 `工作台`、`CRUD`、`联动`、`Target`、`ProbeItem`、`provider evidence`、`timeline evidence` 等内部语言。
- 在子详情里重复 VPS 默认页已经展示过的全部基础字段。
- 在一个弹窗里同时展示多个不相关模块。
- 为了说明交互而显示使用说明文案。

允许：

- `Target` 在技术字段或链接中保留，但默认可见标签优先显示为 `探测对象`。
- IP 质量报告中可以展示数据来源，但中文标题优先使用 `来源`、`IP 数据库`、`服务解锁`，避免英文内部词作为主标题。

### 基础资料

入口：

- 顶部 `基础资料`。

职责：

- 展示默认页不展示的完整 VPS 资料。
- 支持进入编辑基础信息。
- 只服务“核对/修正资料”，不承载订阅、监控、IP 质量和服务域名详情。

布局：

- 顶部摘要：VPS 名称、Provider、地区/数据中心、生命周期。
- 字段分组：
  - 身份与来源：VPS ID、Provider ID、订单号。
  - 访问：IPv4、IPv6、SSH Host、SSH 端口、SSH 用户。
  - 规格：产品名、操作系统、虚拟化、重要性。
  - 管理：标签、备注、归档时间。
- 右上动作：`编辑`。

文案调整：

- 标题用 `基础资料`，不使用 `BASELINE FACTS`。
- 说明文案可以删除；如果必须保留，控制为一句短句：`完整资料仅在这里核对和编辑。`

### 创建/更新订阅

入口：

- 关联概览订阅卡 `更新` 或 `创建`。
- 更多菜单 `创建/更新订阅`。
- 情境工作区缺订阅时的主 CTA。

职责：

- 在当前 VPS 上创建或维护订阅事实。
- 不处理续费决策，不处理生命周期，不做全局成本分析。

布局：

- 顶部摘要：当前订阅状态、价格/周期、续费日、续费方式。
- 表单分组：
  - 金额与周期：价格、币种、计费周期。
  - 时间：开始日期、续费日期。
  - 续费方式：自动续费、手工续费、已取消自动续费等。
  - 支付与备注：支付方式、备注。
- 底部动作：`保存订阅`。

状态规则：

- 有 active 订阅时，标题显示 `更新订阅`，提交按钮显示 `保存订阅`。
- 无 active 订阅时，标题显示 `创建订阅`，提交按钮仍可用 `保存订阅`，避免创建/更新分支在按钮上反复变化。
- 读取失败时不能显示空订阅表单；先显示 `订阅证据暂不可用` 和重试/关闭。

### 延长有效期

入口：

- 订阅卡 `延长`。
- 更多菜单 `延长有效期`。

职责：

- 记录当前 active 订阅的续费日延长或补偿。
- 写入资产历史。

布局：

- 顶部摘要：当前 active 订阅、当前续费日、自动续费状态。

- 底部动作：`保存延长记录`。

状态规则：

- 无 active 订阅时不展示可提交表单，只给 `创建/更新订阅` 入口。

### 监控观测

入口：

- 监控实例卡标题。
- 多实例或无实例时由标题打开本页 `monitoring-instance-evidence` 弹窗。

职责：

- 查看当前 VPS 关联的监控实例摘要。
- 处理接入/升级或解除关联。
- 不替代外部监控详情页。

布局：

- 顶部摘要：实例数、健康状态、最近心跳、活跃异常数。
- 主内容：
  - 0 实例：短空态 + `接入/升级 agent`、`关联已有监控实例`。
  - 1 实例：实例摘要卡 + `接入/升级 agent`、`解除关联`、`打开监控详情`。
  - 多实例：列表展示每个实例的健康、心跳、位置、异常；突出“需核对保留哪个实例”。
- 危险确认：解除关联必须说明只解除 VPS 关联，不删除监控实例或历史数据。

文案调整：

- 标题用 `监控观测` 或 `监控实例`，不使用 `监控实例证据`。
- `active link` 改为 `活跃关联`。
- `创建并接入 agent` 改为 `接入/升级 agent`。

### 接入/升级 agent

职责：

- 没有关联时创建监控实例并进入接入。

布局：

边界：

- 安装命令仍在监控详情的 onboarding 弹窗中生成；VPS 详情页不直接展示敏感命令。

文案调整：

### IP 质量报告

入口：

- IP 质量卡标题。
- 情境工作区高风险/失败状态。

职责：

- 展示当前 VPS 出口 IP 的完整质量分析。

页面顺序：

2. 关键原因：最多 3 个影响当前判断的原因。

7. 诊断与异常。

- `Service Unlock` 改为 `服务解锁`。

- `Context And Coverage` 改为 `采集完整性`。

### 新增服务 / 新增域名

职责：

### 取消/退役

入口：

- 顶部 `当前判断` 的状态动作。
- 外部深链 `/vps/<id>?workbench=cancellation`。

职责：

- 对当前 VPS 做可审计的取消/退役处理。
- 明确选择本次要影响的订阅、监控实例、探测对象。
- 不隐式联动任何对象。
- 不作为正常状态下的常驻危险入口。

入口显示规则：

- 显示：续费决策为迁移、取消或已取消自动续费；生命周期为待迁移、待取消、已取消；或取消预览中存在 warnings/blockers。
- 隐藏：稳定保留、正常续费、无取消/迁移信号时，默认页和更多菜单都不展示 `取消/退役`。
- 深链例外：外部流程仍可打开 `/vps/<id>?workbench=cancellation`，用于资产决策页或历史链接进入处理流程。

布局：

1. 顶部影响摘要：VPS、订阅、监控实例、探测对象。
2. VPS 处理：目标状态、生效日期、原因。
3. 订阅处理：选择要取消自动续费的 active 订阅。
4. 监控处理：选择是否暂停/退役监控实例。
5. 探测对象处理：选择是否暂停/归档探测对象。
6. 服务与域名参考：折叠展示，只提供影响范围上下文。
7. 确认执行：危险按钮。

文案调整：

- 标题用 `取消/退役`。
- `VPS STATE`、`AUDIT`、`SUBSCRIPTIONS` 等英文 eyebrow 改为中文或删除。
- 删除 `普通 CRUD 不会联动`，改为 `只处理本次明确选择的对象。`
- `Target/实例` 改为 `探测对象`。
- `steps` 改为 `项` 或 `已选择`。

安全规则：

- active 订阅不会自动勾选。
- 监控实例和探测对象不会自动勾选。
- 有 blockers 时危险按钮禁用。
- 完成后显示结果摘要，但不把结果插入默认页成为新常驻模块。
