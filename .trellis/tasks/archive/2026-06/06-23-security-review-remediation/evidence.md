# Security review remediation evidence matrix

Status values:

- `confirmed-open`: current code evidence proves the issue exists.
- `fixed`: tests and implementation in this task prove remediation.
- `downgraded`: issue exists but severity / framing from report is not supported.
- `false-positive`: current code evidence does not support the claim.
- `deferred`: accepted hardening, not implemented in this branch yet, with rationale required.
