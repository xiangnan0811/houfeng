# 协作与验证

## 项目与平台权威

根 [AGENTS.md](../../AGENTS.md)、[规范](../spec/README.md)和[设计文档](../design/README.md)是项目权威。Codex、Grok Build、OMP 必须支持；
Claude Code 也须覆盖项目入口。各平台使用原生用户规则、模型、思考等级、Advisor、权限及角色；
不要用项目迁移重写用户配置或导入另一平台的运行时配置。

Claude 的根 CLAUDE.md 仅 `@AGENTS.md`，保持一份规范正文。版本支持不证明 AGENTS fallback
实际启用。子目录/worktree 首次进入可能需要原生界面批准项目级外部导入，不能扩大为全局信任。
OMP 的 `.omp/AGENTS.md` 也只导入根权威，不覆盖用户角色。规范路径和检查命令均以当前 Git root
为准；后端 module 在根，Web 在 `web/`，不是其他项目的 `backend/`。

## 实现和独立审查

- 主控负责范围、决定、整合、修复、验证和交付。已授权实现可以直接完成，也可按需要原生并行委派。
- 实现者需明确文件所有权、约束、相关规范和验收条件；允许修改负责文件并执行检查。
  共享工作区中不得撤销其他操作者修改，出现共享冲突交给主控协调。
- 调查者、独立审查者只读，不自行委派、不修复、不创建任务/日志。它们的限制不影响主控修复权限。
- 非平凡代码、安全/兼容变更及治理/加载变更在交付前必须完成真正独立的 GPT 发现性审查。
  主控自审或 Advisor 意见不能替代；缺少可用 GPT 审查通道时，如实报告必需审查未完成。
- Grok 仅在重大安全、破坏性数据操作、并发/生命周期风险，有证据的高影响分歧，或用户明确要求时补充。
  自动调用还须符合平台原生策略，有可靠的当前配额余量证据和可用通道；配额未知、不足或通道不可用时
  跳过，不探测额度、不轮询等待重置，也不另开替代路线消耗额度。具体阈值和调用方式归平台用户配置。
  缺少可选 Grok 审查本身不阻止交付；用户明确要求的 Grok 覆盖仍须完成，除非用户变更该要求。
- 所有选用的独立审查针对同一候选（基线、文件范围及内容身份），首轮不先共享其他审查者结论。
  完成各路首轮或明确说明中断/不可用路线后再集中修复；不得把其他模型或角色名当作指定模型的审查证据。
- 保持既定原生角色/模型/effort/Advisor，审查调用使用各平台已有能力；不导入 OMP 等其他平台的角色或
  运行时配置，不为审查擅自修改持久默认模型。交付时说明实际覆盖为仅 GPT 或 GPT + Grok。
- 主控按 finding 修复，修复复核检查原 finding 关闭和直接影响；条件不变的有效证据可复用。
  只有范围实质变化或新证据才扩展调查。缺失的必需独立审查和必需原生验收必须列为未完成，不能自证通过。

## 候选、恢复和收尾

证据覆盖基线、暂存 blob、相关未暂存/未跟踪内容、命令及工具链/配置/环境条件。
同一 HEAD 不能证明候选未变；部分暂存、格式化、依赖或配置变化只使受影响证据失效。
只读 readiness 使用只读索引比较，不创建临时 Git index 或私有状态。

提交前检查范围、规范同步、独立审查、测试和适用验收；暂存后复查实际 index，推送前再核对。
主控完成授权修复及相关检查，不以 READY 代替提交/推送/合并授权。交付证据可放会话、PR 或已有
私有恢复记录，不建立仓库 journal。PR/CI/适用合并后流程见分支规范。

恢复可选且留在用户私有目录，按仓库、checkout/worktree、模块和目标选择；不挑“最新”跨项目记录。
已完成或取消事项不是活动工作；历史观察不是当前事实，先核对规范和实际内容。索引仅含指针，
不得复制规范正文和会话历史；只读请求不创建/修复/清理状态，平台正常会话日志另行报告。

## 原生证据边界

改变项目加载/协作入口后，在受影响平台新会话验证；覆盖根、真实后端/前端目录及迁移 worktree
的规范发现和命令工作目录。用自然短请求，不把应读文件或整段迁移指令塞进提示词。
结合原生 source labels 和实际工具事件，区分发现、禁用/遮蔽、选用与已注入内容。
安装清单、磁盘字节、当前进程加载是不同证据；worktree 不能证明用户配置、记忆或服务已隔离。
平台未提供的加载哈希/请求元数据如实记为边界，不为追求字段新建常驻扩展或无限重复验收。

## 真实部署验收

本地测试、CI、发行资产、安装和生产分别验收。维护态、Center/agent 版本升级、逐 ID readback、
通知和被动观察不得用 CI 替代；备份与回滚须覆盖 PostgreSQL、附件及 Records authority 协调恢复。
部署不能由流程迁移自动授权。

历史验收只证明其日期、候选和环境覆盖的范围；未提供原始定义的 finding 不得猜测或标为通过。历史证据通过 Git 追溯，不恢复过期流程目录。
